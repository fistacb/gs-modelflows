# 段階 3: 全体の整理（Gate 1）

- 入力: `02_gen/chosen.ply`, `01_input/landmarks.json` → 出力（確定）: `03_body/body.ply`
- 途中の候補: `03_body/work/`（確定後に消してよい）
- 順序: 数値の検査（`check_candidate.py`、確定時は `verify_gate.py --gate 1`）→ セルフチェック Gate 1 → 独立 QA → 確定時に画像報告

## 1. 基準を決める

`chosen.ply` と原画の高さ・基準位置をそろえ、点群の投影・断面・既存の同条件レンダーを基準にする。修正前後の撮影は同じカメラを使う。横・背面の資料がない場合は、推定した奥行きと接続の根拠を記録する。先に直すのは、姿勢、原画に対する輪郭・比率、部品の接続、可動部の取り付けに影響する差。

## 2. 姿勢 → 大きな面・輪郭 → 静止ディテール

各段で問題が見つかった部位だけを触る。上流（姿勢・面）を作り直したら、影響する下流を見直す。

**直す方針**: 原画にある部位は形も含めて原画に 1:1 で合わせる。原画にない部位（背面・側面・推定部分）は自分でそれらしく作り（人間から指定があればそれに従う）、好みの作り替えはせず破綻を直す。形の破綻（はみ出し・突起・穴・二重面・板状・不自然なふくらみ）は後回しにせず原因の工程で形から直し、そのあとで色・陰影を補正する。色で形の破綻を覆うと後から直せなくなる。色の問題（濁り・しみ・むら）は色で直す（詳しくは SKILL.md 核心ルール 5 と [quality_checklist.md](./quality_checklist.md) 3 章）。

| 順 | 測るものと直し方 | 次へ進む条件 |
| :--- | :--- | :--- |
| 姿勢 | 正面で腕の高さ・向き、真横で足首・膝・腰・肩・頭の前後位置を見る。関節位置や断面重心を使い、傾いた部位を移動・回転する。靴底と体幹の傾きは別々に見て、髪やマントを体幹の基準から外す。**真横の体幹の傾き ±8°・靴底 ±3° は数値で測る**（`check_candidate.py`）。体全体の前傾・後傾は [correct_posture.py](../scripts/correct_posture.py) で取る（S 字のふくらみは残し、首から上は曲げない）。 | 接地が保たれ、頭・胴・四肢が指定の姿勢に見える。 |
| 大きな面・輪郭 | 正面で原画との輪郭と**ランドマーク高さ**（正面レンダーで同じ目印を [measure_landmarks.py](../scripts/measure_landmarks.py) `--pairs-with 01_input/landmarks.json` で測り、ずれは [align_rows.py](../scripts/align_rows.py) で高さ方向に合わせる）、斜めと真横で頭・頬・顎、首と襟、肩と胴、髪・衣装の厚みと接続を見る。**`+60°` では遠い側のこめかみ・頬の厚み**を見る（薄いと段階 4 の眉・まつ毛・目尻が輪郭からはみ出す）。平板さや浮きは断面で奥行きを測る。位置のずれは移動・回転、曲面や厚みの不足は局所変形、欠けや二重面は除去・再構成で直す。 | 正面の輪郭とランドマーク高さが原画に合い、斜め・横からの厚みと接続が成立し、目・口を載せる顔面が定まっている。 |
| 静止ディテール | 確定した面を基準に、衣装の柄・装飾や、可動化後も残る顔の部分を整える。顎下・首・襟などの境界をまたぐ過大スプラットと、ぎざぎざの輪郭もここで掃除する。体から離れた浮遊塊は [remove_detached.py](../scripts/remove_detached.py)（デザイン上の離れた部品は `--box` で守る）。目・口は位置と開口の手がかりが読める状態まで整え、可動化は段階 4 で行う。 | 原画の主要な特徴が読めて、面から浮く点や目立つ二重線がない。 |

## 3. 試行の進め方

- 着手前に「部位・ずれの根拠・採用条件」を `qa/attempt_log.md` に 1 行で書く（問題 ID を振る）。
- 1 回の試行は [check_candidate.py](../scripts/check_candidate.py) 1 回（`--ref` に直前の採用 PLY、`--protect` に触らない範囲）。数値で落ちた候補は見ない。調整中に撮るのは、直した部位が見える角度だけ（姿勢なら 90°、面なら該当角度）を前後比較で（`render_views.py --only full:90 --ref <直前の採用 PLY>`）。
- 変形は [splat_ops.py](../scripts/splat_ops.py) の `transform_gaussians` を使い、[quality_checklist.md](./quality_checklist.md) の「変形・再構成のときの必須確認」（折り返し・保護範囲の不変・更地化・隣接リングからの配色・過大スプラット）を守る。
- 髪・襟などで形が欠ける、癒着する、または移動・変形で輪郭を合わせても曲面が崩れる場合は、対象と前後の層を奥行きと断面で切り分ける。根元と隣接部を保護し、置き換える旧スプラットを除去して、同尺度の原画で測った根元・先端・幅に沿う先細りの曲面を作る。奥行き、接続、配色は根元・隣接面の実測を使う。曲面を作り直す必要が判明した時点で再構成を試し、同じ変形の強弱だけで試行枠を使わない。
- 独立した部位は個別に計測してから統合する。正面投影の輪郭、高さ・幅、根元の接続、他部位への干渉を先に検査し、通った候補の継ぎ目や重なりを最少の視点で確認する。旧点群と再構成面の接合では座標・奥行き・色の三つを照合する。
- 色替えの対象点は [front_select.py](../scripts/front_select.py) で「正面から見えている点」に絞り、本番の前に赤いタイント版を撮って選択の漏れを確かめる。
- 原画にない部位の見た目（形の好み）を理由に試行を重ねない。破綻がなければその部位は完了とする。破綻があれば形の修正も含めて直す。
- 縞や帯を見つけたら、直す前にレンダラー設定を変えて撮り直し、撮影側の問題を除外する。
- 同じ ID が 3 回で収束しなければ止めて、最良候補と残る差を添えてユーザーに確認する。シードを替える場合は段階 2 から再開する。

## 4. リグを付けやすい姿勢かの確認（段階 5 の前提）

確定前に次を確かめる。崩れていると段階 5 で関節位置・ウェイトが破綻する。

- 腕が体幹から離れていて（目安 T ポーズ 75°〜85°）、脇・手と胴・スカートが癒着していない。
- 肘・膝・手首が左右で同じ高さにあり、左右の腕・脚の長さがそろっている。
- 足が床に接地し、両足の間がつながっていない。
- 長い髪・マント・持ち物が胴や腕と癒着していない（癒着がある場合は [character_conditions.md](./character_conditions.md)）。

## 5. 確定時

1. 全身・バストの固定撮影セット（[quality_checklist.md](./quality_checklist.md) 1 章、真横 90° を含む）を撮る。
2. `verify_gate.py --gate 1`（縦横比・浮遊点・高さ・真横の傾き・靴底）。
3. セルフチェック Gate 1 を全項目「済」にする。
4. 元デザイン画付き独立ブラインド QA を 1 回（結果は文字で受け取る）。FAIL なら指摘を 1 件ずつ直さず、[quality_checklist.md](./quality_checklist.md) §6 のとおり原因工程からやり直す。
5. 両方が通ったら `body.ply` として固定し、`qa/stage_3_handoff.md` を書き、ユーザーへ比較シート 1 枚で報告する。
