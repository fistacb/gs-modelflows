# 用途オプション

用途に応じて選ぶ。どのオプションも、元の段階の確定ファイルを上書きしない。

## 小物の追加（リュック・ポーチ・鞘・羽・手持ちの武器など）

正面図から見えない、または手と癒着すると困る立体の小物を足すとき。

1. キャラ本体は小物なしで段階 1〜5 を通す。
2. 小物単体の正面図 1 枚から TripoSplat で個別に生成・正規化する（`65,536` 点で十分）。
3. Python で小物のスケール・位置・回転を合わせ、親ボーン（`chest` / `pelvis` / `hand_R` など）へ剛体で取り付ける（静止時は単純に連結、アニメーション時は親ボーンの変換を適用）。
4. 取り付けた状態で、取り付け部の固定撮影と確認動画の該当パートを撮り直す。

## 演技ムービー・納品用の動画

段階 5 の確認動画とは別に、演技や納品のための動画を作るとき。

- 凍結した `v1/` だけから作る（[step9_walk_oblique_video.py](../scripts/step9_walk_oblique_video.py)、[step8_v1_package_test_video.py](../scripts/step8_v1_package_test_video.py) を元にする）。描画は段階 5 と同じ Spark GPU `SplatSkinning`。
- モーションの符号（上向きボーンと下向きボーンの X 回転の向き）と、腕の大振りの合成方法は [package_v1_spec.md](./package_v1_spec.md) のトラブルシューティング。
- `verify_gate.py --gate 4` を通し、独立 QA は `.mp4` 本体で確認してから提出する。

## 下流スキルへの受け渡し

- **gs-to-sprite**（2D スプライト・GIF）: `v1/master.ply` と `rig_skeleton.json` を渡す。動きは段階 5 と同じボーン姿勢の形式で渡す。
- **gs-to-mesh**（印刷用メッシュ・STL / GLB）: `v1/master.ply` を渡す。印刷向けには静止ポーズで十分なので、動く目・口は閉じた状態（開眼・閉口）で固定した PLY を書き出して渡す。
- 受け渡し時は `meta.json` の対応パイプラインの宣言を確かめる。
