# キャラ条件別の追加手順

当てはまる条件だけ読む。どの条件でも段階・確定時の検査（真横 90° を含む固定撮影セット、verify_gate、セルフチェック、独立 QA）は省略しない。

## 顔のアクセサリー（眼鏡・目元の装飾など）

- 段階 3: フレームを顔面と別の奥行きで分けて記録し、以降の変形の保護範囲（`check_candidate.py --protect`）に入れる。
- 段階 4: 3D の奥行き分離と金属・固有色の保護でフレームを守りながら、フレーム内側のレンズ空間・頬・鼻筋の残った汚れを除去する。まぶた・眼球の外側の端がフレームの外へはみ出ない幅に収める。
- 段階 5: アクセサリーは `head = 1.0` に含める。首振り ±18° でフレームと目の位置関係が変わらないことを確かめる。

## 長い髪・マント・尻尾

- 段階 3: 体幹の傾きは髪・マントを除いて測る。中央値の線が引っ張られて数値が外れる場合だけ、`character_config.json` の `qa_thresholds.max_trunk_lean_deg` を変え、理由を書く（[efficiency.md](./efficiency.md) 2 章）。直立は靴底の平面を基準に確かめる。
- 段階 3: 背面・側面で帯状・板状に見えないよう、推定部分に自然な厚みを持たせる。腕・胴・スカートとの癒着はここで切り離す。
- 段階 5: 頭から 3D でつながる背面・側面の長い髪は `head = 1.0` に含める（首振りでちぎれないため）。手の近くのスカートが腕のウェイト（`arm_core`）に入らないよう、腕の候補を腕のボーンの筒と手先の半径に限る。

## 背面・側面の資料がある

- 段階 1: 資料は TripoSplat に入れず（単一画像専用）、段階 3 の参考として保存する。
- 段階 3: 背面・側面のシルエットと主要な柄の位置を資料と比べ、推定ではなく資料に合わせて直す。背中のロゴ・柄だけを足したい場合は、背面資料から該当範囲のスプラットへ背面投影で着色する。
- 独立 QA の依頼文で「側面・背面は推定でよい」とせず、資料も添えて判定してもらう。

## 細密キャラ・高頭身キャラ（262k 点）

- 段階 2: `262,144` 点で生成する。点数が増えるぶん処理が重くなるので、シード数は 2〜3 にし、比較は数値で落とせるものを先に落とす。
- 顔が小さい場合も頭部の別生成・移植はしない。原画の顔解像度が足りなければ、段階 1 で高解像度の単体図に差し替える。
- 段階 3・4: 点の間隔が細かいので、孤立成分・過大スプラットの判定値（kNN 半径など）を点の間隔に合わせて決め直す。
