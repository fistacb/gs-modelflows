# 段階 4: 顔の調整（Gate 2・必須）

- 入力: `03_body/body.ply` → 出力（確定）: `04_face/head_base.ply`, `04_face/eyes/`, `04_face/mouth/`, `04_face/face_states.json`
- **すべてのキャラで必ず行う**（静止の目・口のまま進めない）。瞬き・ウインク・視線移動ができる目とまぶた、開閉と「あいうえお」ができる口を作る。
- 順序: 顔ディテールの整理 → 動く目 → 動く口。数値の検査 → セルフチェック Gate 2 → 独立 QA → 確定時に画像報告。
- 調整中の軽い確認は顔アップ `0°` と `+60°`。ただし **目・まぶたの工程を 1 周作り終えたら、QA の前に全状態 × `0° / ±35° / +60° / ±90°` の 1 枚シートを自分で見る**（`±35°` と視線左右でしか出ない不具合が多い）。

## 1. 顔ディテールの整理

- **旧部品を残さない**: 対象範囲の旧まつ毛・旧虹彩・旧口線・ぼやけた影を先に除去する。残して上から重ねると、閉眼時の二重線や斜めの浮きになる。再構成した肌（まぶた・目の下・口元）の色は、境界のすぐ外側の肌から取る。
- **顔の肌の色の外れ値**: 目の下・頬・鼻の横に原画にない赤い点・青紫のしみがあれば、周りの肌色（近傍の中央値）へ色で直す（色の問題なので形は触らない）。
- **まつ毛の色**: 原画のまつ毛の色（黒に近いなど）に合わせる。生成の茶色が残っていれば、まつ毛帯の暗い点だけ色を替える。
- 顔のアクセサリー（眼鏡など）がある場合は [character_conditions.md](./character_conditions.md)。

## 2. 動く目

- スクリプト: [step2_fit_skeleton.py](../scripts/step2_fit_skeleton.py) → [step3_carve_sockets.py](../scripts/step3_carve_sockets.py) → [step5b_polish_splats.py](../scripts/step5b_polish_splats.py) → [step4_generate_eyeballs.py](../scripts/step4_generate_eyeballs.py) → [step4b_eyelid_shell_test.py](../scripts/step4b_eyelid_shell_test.py)
- **相対スケール**: 眼球半径・くり抜き・まぶたシェルの幅と高さ・上まつ毛ラインは、眼間距離 `D_eye`・顔幅 `W_face`・顔面の曲率 `y_surf(dx, dz)` の実測値から算出する。
- **眼球を入れる前に固定の目の縁と顔面曲面を確認する**: 正面と斜めで、目尻・まつ毛が肌から浮いていないかを見る。`step2_fit_skeleton.py` は左右別に開口周囲の肌点からロバスト 2 次曲面 $y_{\text{face}}(x, z)$ をフィットし、`depth_fit`（`skin_surface_y`, `normal`, `fit_rmse_mm`, `rim_flush_err_mm`）と `face_quad_coef` を記録する。`skin_surface_y` が `null`、または `fit_rmse_mm > 1.5`・`rim_flush_err_mm > 2.0` のときは、眼球中心が局所法線からずれて出っ張り・くぼみが出やすいため、断面と `+60°` で確認してから進む。
- **元の頬肌・チークを壊さない（手前貼り肌フレーム禁止）**: 眼球の縁を隠す目的で頬の上に平たい肌リングを手前貼りすると、チークのグラデーションが潰れて目の下に楕円の段差が出る。くり抜き範囲を虹彩＋狭い白目の最小限に絞り、眼球を局所法線方向へ均一に収めて元の頬肌をそのまま活かす。
- **上まつ毛は単一ソースにする（二重重ね禁止）**: `head_base.ply` に静的上まつ毛を焼き込んだ上で `build_eyelid_shell(..., always_draw_lash=True)` を重ねると二重の灰茶色の帯になる。静的上まつ毛は焼き込まず、`build_eyelid_shell(..., always_draw_lash=True)` だけで開眼・半目・閉眼・ウインク・動画の全フレームを統一描画する。
- **目元超拡大 50/50 比較（必須）**: 30 パネル縮小シートだけでは 10〜20 px の位置ズレ・チーク境界の段差・二重まつ毛を見逃しやすい。QA の前に必ず「原画・素体 `body.ply`・加工後（および素体との 50/50 重ね合わせ）」の**同一カメラ目元超拡大比較（約 300 px 級、`0° / +35° / +60°`）**を作り、位置一致・白目比率・面密着（浮き・くぼみ・飛び出しゼロ）を確認する。
- **固定の縁に突起がある場合**: 固定の縁だけと眼球を重ねた状態を同じ視点で比べ、どちらが輪郭を崩しているかを確かめる。縁が原因なら目頭・目尻と肌面の接続を先に整える。中心の奥行きが肌面の範囲内でも、点の広がりや開口の横幅で突起が見えることがある。くり抜きは元の目の点群を基準にし、突起・目尻の隙間・白目の漏れを確かめてから可動まぶたへ進む。
- **単一アーモンド開口曲線と高密度マイクロスプラット**: くり抜き・上まつ毛・可動まぶたの肌カーテン（まつ毛ラインより上だけに作り、下へのにじみを防ぐ）・動的な隠れを **同じパラメトリック曲線** でそろえ、二重まぶたを防ぐ。
- **開口の内側に眼窩の壁を見せない**: くり抜いた面の奥の点（眼窩の壁）が、`±35°`・`+60°`・視線左右でまぶたの開口の内側に見えると、眼球の縁が白い弧に見える。くり抜きの工程で、開口の内側から見える壁の点は白目の端の色に替えるか隠す。
- **眼球の覆い範囲**: 生成の眼球が前面のキャップだけのとき、覆い範囲が「開口の半角＋視線角＋視点角」に足りないと、縁で裏側が見えて粒・筋・ぎざぎざになる。白目の帯を約 115° まで足し、間隔はスプラットの広がり（σ）の 1.2 倍未満、等方のスプラットにする。追加した点はタイント版で確かめる。
- **まぶたの肌はまつ毛ラインで止める**: まぶたの肌カーテン・くり抜きの縁の処理は、深い縁の帯は隠し、浅い縁の帯は周りの肌色に替える。まぶたの寸法（rx, rz）はテンプレートの値ではなく実測の開口に合わせる。
- **視線（輻輳）**: [harmonic_dqs.py](../scripts/harmonic_dqs.py) の `look_at_eye_rot` でカメラ距離に両眼を向ける。

## 3. 動く口

- スクリプト: [procedural_mouth.py](../scripts/procedural_mouth.py)（`detect_mouth_landmarks` → `carve_mouth_pocket` → `build_procedural_mouth`、`MOUTH_PRESETS`: `closed`, `smile`, `A`, `I`, `U`, `E`, `O`）。口の位置・幅は検出値をそのまま使わず、原画の口と正面レンダーを並べて確かめる。
- **構造**: 元のぼやけた口線・影を肌色で中和し、開口の内側だけを小さくくり抜く。ベース頭部はそのまま、閉口は隙間のない細い口線、開口は奥まった口腔・舌と上唇だけの細くなる輪郭線（下唇は線なし＋淡い影）を動的に描く。
- **追従**: 口パーツは `head` 100% の剛体追従ではなく、口周りのあご肌スプラットの DQS ウェイト平均（`w_mouth_anchor`）で追従させる（段階 5 の首振りでずれないため）。

## 4. 確定時

1. 顔の固定撮影セット（`0° / ±35° / +60° / 90°`）と全状態（開眼・半目・閉眼・ウインク・視線左右、口の閉 / あ / い / う / お）を撮る。原画と 1:1 のバスト比較＋目元・口元の拡大比較も作る。
2. `verify_gate.py --gate 2`（バスト縦横比・浮遊点・前後比較シート）。`render_front` には切り抜いていない全身の正面レンダーを渡す（バストの切り抜きを渡すと上端見切れで FAIL になる）。Windows では `PYTHONIOENCODING=utf-8` を付けて実行する。
3. セルフチェック Gate 2 を全項目「済」にする（眼球の目頭のめり込み・目尻の飛び出し・下まぶたの段差・閉眼まぶたと頬の色・首/襟/アクセサリー周りの掃除）。
4. 元デザイン画付き独立ブラインド QA を 1 回。FAIL なら指摘を 1 件ずつ直さず、[quality_checklist.md](./quality_checklist.md) §6 のとおり原因工程からやり直す。
5. 通ったら確定し、`qa/stage_4_handoff.md` を書き、ユーザーへ比較シートで報告する。首振り ±18° は段階 5 でリグを付けてから確かめる。
